# Blaze

**Твои виджеты. Твой рабочий ритм. На экране. Всегда.**

Blaze — приложение для создания и настройки личных виджетов рабочего стола. Быстрая заметка, маршрут из дома на работу, таймер фокуса и рабочие дни собираются в своё пространство: нужные инструменты остаются под рукой, а день становится понятнее.

Идея вдохновлена свободой виджетов на MacBook. Текущая реализация — ранний прототип для **Windows**, построенный на Electron. Макеты показывают направление продукта; отдельные детали и сценарии ещё развиваются.

> **Статус: 0.1.0 · прототип в разработке.** Репозиторий пока закрытый. Рабочие функции, дизайн-концепции и будущие возможности описаны отдельно, чтобы оценивать проект по его реальному состоянию.

## Ваш рабочий стол — по-вашему

Blaze объединяет три повседневные задачи: быстро записать важное, подготовиться к следующему действию и увидеть, как прошла работа. Пользователь выбирает виджеты, меняет их цвет и размер, размещает отдельные окна на экране и закрепляет их поверх других приложений.

Это пространство для людей, которые работают за компьютером: дизайнеров, разработчиков, студентов, фрилансеров и всех, кому важно меньше переключаться между инструментами.

## Что уже можно делать

| Возможность | В текущем прототипе |
| --- | --- |
| Свои виджеты | Добавлять виджеты из библиотеки, менять название, размер, цвет; использовать собственный HEX-цвет |
| Заметки | Сохранять текст и список задач, отмечать выполненные пункты |
| Рабочий стол | Открывать каждый виджет отдельным окном, таскать за заголовок, закреплять и откреплять поверх окон |
| Быстрый маршрут | Вводить два адреса, выбирать общественный транспорт, машину или пеший путь; открывать Яндекс Карты Москвы и области |
| Активность | В Windows учитывать время активной программы и просматривать график, распределение времени и последние сессии |
| Рабочие дни | Отмечать дни, записывать часы и комментарий, задавать месячную цель |
| Фокус | Запускать общий таймер, ставить на паузу, продолжать и добавлять пять минут |
| Забота о себе | Настраивать напоминания о воде, движении и перерывах |

Метро, МЦД, электрички, варианты маршрутов и время в пути предоставляет Яндекс внутри своей карты. Компактная схема маршрута в оформлении — иллюстрация; она не является самостоятельным расчётом дороги.

## Быстрый запуск для разработки

Требуются Node.js 22.12+ и pnpm 10. Для отдельных окон и учёта программ нужна Windows.

```powershell
git clone https://github.com/kartaamigo/Blaze.git
cd Blaze
pnpm install --frozen-lockfile
node node_modules/electron/install.js
pnpm check
pnpm start
```

В закрытый репозиторий нужен доступ владельца или приглашённого участника. Ручная установка Electron указана отдельно: pnpm может блокировать скрипт загрузки бинарного файла.

Для предпросмотра интерфейса в браузере:

```powershell
pnpm preview
```

Откройте `http://127.0.0.1:4173`. Отдельные окна Windows, учёт активной программы и системные уведомления в таком режиме недоступны. Подробности — в [инструкции](docs/DEVELOPMENT.md).

## Данные и ограничения

Заметки и настройки хранятся локально в хранилище Electron. Учёт программ и история сессий — в каталоге приложения Windows. Названия активных процессов учитываются примерно раз в пять секунд; после минуты без ввода учёт приостанавливается. Содержимое окон и нажатия клавиш приложение не записывает.

Адреса, введённые для маршрута, передаются Яндекс Картам. Для карты требуется интернет. Облачной синхронизации, аккаунтов Blaze, мобильной версии и интеграции с системными виджетами macOS пока нет. Таймер не восстанавливается после полного выхода. Закрытие основного окна оставляет Blaze в трее; завершить приложение можно через меню трея.

В репозиторий включены исходники и материалы проекта. Пользовательские заметки, статистика, резервные копии, журналы и установленные зависимости не загружаются.

## Куда развивается Blaze

Ближайшая цель — удобная и стабильная Windows-версия: сохранение расположения виджетов, готовая установка, понятное управление данными и проверка основных сценариев. Следующие идеи — наборы виджетов «Работа», «Учёба», «Дорога», шаблоны заметок и обзор недельного прогресса. Это планы, а не обещания готовых функций.

Полный список — в [плане развития](docs/ROADMAP.md).
